FLEET PERFORMANCE & FUEL LOSS INVESTIGATION

Project Overview

This project is a Data Analytics / Business Intelligence case study focused on analyzing fleet operations and fuel-event data to identify performance issues, unusual patterns, and potential fuel-loss risks.

The analysis covers fleet performance, fuel efficiency, driver idle time, route compliance, and fuel-drop events, with the findings translated into actionable business recommendations.

━━━━━━━━━━━━━━━━━━━━━━

Business Objectives

• Validate and clean fleet and fuel-event data
• Develop operational KPIs
• Analyze vehicle and driver performance
• Identify low fuel-efficiency vehicles
• Investigate high idle-time patterns
• Analyze route compliance
• Identify suspicious fuel-drop patterns
• Translate findings into business recommendations
• Build a management-focused Power BI dashboard
